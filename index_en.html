03Project Overview

Research on agent interaction and learning, generation efficiency, and interactive environment modeling.

LLM Post-training and Agents

1. Coding Agent Task Construction: I turn real fixes from open-source repositories into executable coding tasks. Issues and merged PRs provide the problem description, pre-fix code, reference patch, and tests. The pipeline builds container environments and evaluation scripts, then checks that the reference fix passes the tests and that the original code exposes the reported problem. Agents read code, use tools, modify implementations, and run tests in these environments, producing interaction trajectories for training.

2. Value Estimation and Credit Assignment for Long-Horizon Tasks: Coding tasks often require many attempts before a final outcome is available, making a single success or failure signal insufficient to assess intermediate steps. Drawing on the Actor–Critic design in PPO, I train a Critic on final task outcomes to predict the probability of eventual success given the current interaction history. Changes in predicted value before and after an action and its environment feedback estimate progress at each turn and determine distillation weights. The Critic is continually updated with new student trajectories as the student improves.

3. Asynchronous Training for Multi-turn Agents: Tasks vary widely in interaction length, tool execution time, and test duration, so waiting for an entire batch to finish can leave training idle. I organize interaction data by turn and connect trajectory generation, teacher scoring, and training updates asynchronously, allowing ready data to be processed promptly. Critic learning that requires final outcomes takes place after task completion. Reusing historical computation states allows incremental scoring of newly added context, reducing repeated computation along long trajectories. I also address model version consistency and supervision alignment during asynchronous execution.

4. On-Policy Distillation and Cross-model Knowledge Transfer: For Coding Agent tasks, I work on Agentic OPD from Qwen3.5-27B to Qwen3.5-9B. The teacher provides token-level supervision on responses actually generated by the student, while Critic value changes adjust supervision strength across turns. For cross-model distillation, I use cross-tokenizer probability alignment and event completion for cross-vocabulary, heterogeneous MoE distillation from Kimi 2.7-1T to Qwen3.6-35B-A3B, as well as knowledge transfer from Qwen 397B to 30B. I also work on MOPD-based merging of Math, Code, and instruction-following capabilities, evaluating how well each capability is retained after merging.

Efficient Multimodal Generation

I study how feature dynamics across timesteps, network layers, and frequency bands can reduce redundant computation in image, video, and speech generation. My work spans training-free extrapolation, prediction and calibration, learnable and stage-aware predictors, adaptive verification, and computation allocation, alongside surveys of caching methods and efficient attention. The central questions are which computations can be reused or predicted, when to recompute, and how to preserve quality under acceleration.

This direction also covers how computation is organized throughout generation: progressive resolution, spatiotemporal token selection, noise-trajectory selection, and KV selection and quantization for autoregressive video. In image editing, I explore semantic preservation and local changes; in speech generation, frequency- and wavelet-guided extrapolation. Together, these studies investigate efficiency across features, space, time, and tasks.

Interactive World Models

I study how video generators can model controllable environments with sustained interaction, responding to natural-language instructions and player actions while preserving scene, state, and history consistency over long horizons. My work spans interactive video data construction, cleaning and annotation, interaction-memory teacher-model SFT, and evaluation of instruction following, action response, and temporal consistency.

For training and inference, I work on Self-Forcing / DMD few-step distillation and reinforcement learning for long-horizon stability and visual quality. This research considers control, interaction memory, and generation efficiency together, aiming to produce coherent interactions under continuous feedback.

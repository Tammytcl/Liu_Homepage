03项目介绍

以下介绍我正在开展及此前参与的研究工作。

大语言模型后训练与智能体

1. Coding Agent 任务构建： 将开源仓库中的真实修复记录转化为可执行的代码任务：从 Issue 和已合入 PR 中提取问题描述、修复前代码、参考补丁与测试，构建容器环境和评测脚本，再检查参考修复能否通过测试、未修复代码能否暴露原有问题。任务交付后，Agent 在环境中阅读代码、调用工具、修改实现和运行测试，产生用于训练的交互轨迹。

2. Long-Horizon 任务的价值估计与信用分配： 代码任务往往经过多轮尝试才得到最终结果，单个成败信号很难反映中间步骤的作用。我借鉴 PPO 的 Actor–Critic 设计，用任务最终结果训练 Critic，预测当前交互历史下的后续成功概率。通过比较行动及环境反馈前后的价值变化，估计每一轮的任务进展，并据此调整蒸馏权重。Critic 随学生产生的新轨迹持续更新，适应学生能力的变化。

3. Multi-turn agent 的异步训练： 不同任务的交互轮数、工具执行和测试耗时差异很大，等待整批任务结束会造成较长的训练空闲。我按轮组织交互数据，将轨迹生成、教师评分与训练更新异步衔接，让已就绪的数据及时得到处理；需要最终结果的 Critic 学习则在任务完成后进行。同时复用历史计算状态，只对新增上下文做增量评分，减少长轨迹中的重复计算，并处理异步执行中的模型版本与监督对齐问题。

4. On-Policy Distillation 与跨模型知识迁移： 在 Coding Agent 任务上，开展 Qwen3.5-27B → Qwen3.5-9B 的 Agentic OPD，由教师对学生实际生成的响应提供逐 Token 监督，并用 Critic 的价值变化调整各轮监督强度。在跨模型蒸馏中，通过跨 Tokenizer 概率对齐与事件补全，实现 Kimi 2.7-1T → Qwen3.6-35B-A3B 的跨词表、异构 MoE 蒸馏，以及 Qwen 397B → 30B 的知识迁移。此外，开展基于 MOPD 的 Math、Code 和指令遵循能力合并，检查合并后各项能力的保留情况。

代表工作： ESCD · PHYRD · BigBang · TRAIL (进行中)

高效多模态生成

围绕图像、视频与语音生成中的重复计算，我研究如何利用特征随时间步、网络层级和频段变化的规律，减少昂贵的模型计算。相关工作覆盖免训练特征外推、预测与校准、可学习及阶段感知预测、自适应验证和计算分配，并从理论与综述角度梳理缓存方法及高效注意力机制。核心问题是：哪些计算可以复用或预测，何时需要重新计算，以及如何在加速时保留生成质量。

这一研究主线也延伸到生成过程本身的计算组织，包括渐进分辨率、时空 Token 选择、噪声轨迹选择，以及自回归视频中的 KV 选择与量化；在图像编辑中关注语义保持与局部修改，在语音生成中探索频域与小波引导的外推。通过结合特征、空间、时间和任务层面的计算策略，探索适用于多种生成与编辑任务的效率方法。

代表工作： FreqCa · LESA · SpeCa · TaylorSeer

交互式世界模型

我关注生成模型如何从单向的视频合成走向可控制、可持续交互的环境建模：既响应自然语言指令和玩家动作，也在长时序生成中维持场景、状态与历史的一致性。相关工作贯穿交互视频数据构建、清洗与标注，交互记忆教师模型 SFT，以及指令跟随、动作响应和时序一致性的评测。

在训练与推理方面，基于 Self-Forcing 与 DMD 开展少步蒸馏，并结合强化学习优化长程生成稳定性与视觉质量。研究重点是将控制能力、交互记忆与生成效率一起考虑，使世界模型能够在持续反馈中生成连贯的交互过程。

代表工作： Hunyuan-GameCraft-2
